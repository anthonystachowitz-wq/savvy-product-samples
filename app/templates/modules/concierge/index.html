How this is built

Prompt pattern. One call per question. The household record is flattened to a field table of {{ household.fields|length }} paths, each with a label and an exact value string. The system prompt requires strict JSON with an intent, a short plain answer, a citation list, and a route flag. Advice and transaction questions are refused in the prompt and routed.

The deterministic check. Code, not the model, decides whether an answer is grounded. Every cited path must exist in the record with the same value. Every number in the answer, after ids and dates are stripped, must appear in a cited value. A failure is shown on the page and blocks release, even when the advice boundary held.
